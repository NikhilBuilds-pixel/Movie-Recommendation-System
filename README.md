# 🎬 Movie Recommendation System

A desktop-based Movie Recommendation System developed using **Python**, **Tkinter**, and **MySQL**.

## 🚀 Features

- 🎯 Recommend movies based on Genre
- 🌐 Filter by Language
- ⭐ Filter by Rating
- ➕ Add new movies to database
- 🗄️ MySQL database integration
- 🖥️ User-friendly Tkinter GUI

## 🛠 Technologies Used

- Python
- Tkinter
- MySQL
- MySQL Connector
- SQL

## 📂 Project Structure

```
Movie-Recommendation-System/
│
├── main.py
├── SQL.sql
└── README.md
```

## ▶️ How to Run

1. Install Python
2. Install MySQL
3. Import SQL.sql into phpMyAdmin
4. Install mysql-connector-python

```bash
pip install mysql-connector-python
```

5. Run

```bash
python main.py
```
